Summary of the Projeto-PO Repository
Objective:
The repository aims to create a management system for a hotel that includes managing animals, employees, habitats, vaccines, and performing various lookups.

Main Components:

App.java:

Entry point of the application.
Initializes the HotelManager and imports data if available.
Opens the main menu to interact with various functionalities.
Main Menu (Menu.java):

Provides options to create, open, and save files.
Allows advancing the season and viewing global satisfaction.
Opens sub-menus for managing animals, employees, habitats, vaccines, and lookups.
Animal Menu (animal/Menu.java):

Visualize all animals.
Register a new animal.
Transfer animals to habitats.
Show satisfaction of individual animals.
Employee Menu (employee/Menu.java):

Visualize all employees.
Register new employees.
Add or remove responsibilities.
Show satisfaction of employees.
Habitat Menu (habitat/Menu.java):

Visualize all habitats.
Register new habitats.
Change habitat area and influence.
Add trees to habitats and show all trees in a habitat.
